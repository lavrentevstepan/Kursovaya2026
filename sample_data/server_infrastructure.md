# Конфиденциальный регламент доступа к серверам и базам данных

## Раздел 1. Архитектура защищенного контура
Все производственные серверы СУБД размещены в изолированном сегменте VLAN 100 и не имеют прямого доступа из глобальной сети Интернет.
Доступ к узлам баз данных возможен исключительно через выделенный Bastion-хост с адресом 10.20.0.5 по протоколу SSH с двухфакторной аутентификацией.

## Раздел 2. Управление привилегированными ключами
Прямой вход под учетной записью root на боевые сервера категорически запрещен.
Вход выполняется только с использованием индивидуальных SSH-ключей ed25519, подписанных корпоративным центром сертификации на срок не более 8 часов.
Парольный вход по SSH отключен на уровне конфигурации демона sshd (PasswordAuthentication no).

## Раздел 3. Аудит и резервное копирование
Каждая административная сессия записывается с помощью утилиты tlog и передается на выделенный сервер неизменяемого аудита.
Резервные копии баз данных создаются ежедневно в 02:00 UTC, шифруются алгоритмом AES-256-GCM и реплицируются в холодное геораспределенное хранилище.
